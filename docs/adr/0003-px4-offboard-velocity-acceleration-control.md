# PX4 Offboard Velocity and Acceleration Control

## Context
Autonomous trajectory execution and swarm formation flight require dynamic, smooth, and collision-free path adjustments. We need to define the control interface between higher-level mission planners (and swarm MPC) and the PX4 Autopilot firmware.

## Decision
Control UAVs using PX4 Offboard mode via MAVLink (`SET_POSITION_TARGET_LOCAL_NED`), streaming 3D velocity setpoints along with acceleration feed-forward values generated by higher-level controllers (such as the swarm MPC), rather than relying on discrete waypoint uploads or raw attitude setpoints.

## Why
Streaming velocity and acceleration feed-forwards allows smooth real-time trajectory updates, rapid collision avoidance maneuvers, and tight multi-drone coordination while leaving attitude stabilization and inner-loop rate control to PX4.
